# Portfólio Acadêmico

Portfólio acadêmico de Gabriel da Cunha de Macedo apresentado em página web estática.

## Conteúdo

O portfólio é dividido em três seções principais:

- **Início** – apresentação pessoal e resumo da trajetória acadêmica
- **Carreira** – trajetória formativa e competências técnicas e comportamentais
- **Projetos / APIs** – detalhamento dos projetos semestrais do curso

## Tecnologias

Página web construída com HTML, CSS e JavaScript puro, sem dependências externas.

## Acesso

A página será publicada e pode ser acessada diretamente pelo navegador.
